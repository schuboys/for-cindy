Everything here is yours — no sign-in, no accounts, nothing phoning home. Pick whichever one fits the screen you’re looking at.

Wallpapers · .zip Desktop and phone sizes. Windows: unzip, right-click a PNG → Set as desktop background. iPhone: save to Photos → Settings → Wallpaper. Stills pack (screensaver) · .zip Unzip into a folder. Windows: Settings → Personalization → Lock screen → Screen saver → choose Photos → Browse to that folder → Save. CindyDrift · .scr The real moving screensaver. Right-click the file → Install. Windows may show a blue SmartScreen box — click More info → Run anyway. (If your work laptop blocks it, use the stills pack above.) Phone loop · .mp4 iPhone: save the video to Photos, then either convert it to a Live Photo (any “video to Live Photo” app) and set it as your lock screen, or use the stills as a lock-screen photo shuffle. Desktop loop · .mp4 1920×1080 version of the same drift — nice on a second monitor or a TV.
